This is a repository of assignments I completed as a trainee at Revature during the fall of 2026. It is divided into subfolders according to week:
- `Week_2/`: Core Java: Core concepts, user input, REPL, and `java.time` package.
- `Week_3/`:
  - PostgreSQL: Data queries (SELECT, UNION, JOIN), data manipulation (INSERT, UPDATE), data definition (CREATE).
  - PL/pgSQL: Conditional control flow, common table expressions, functions, stored procedures.

Some files are coding challenges assigned by my trainer. Coding challenge files are formatted such that for each subchallenge, the file has a comment explaining the subchallenge, followed by my code answering the subchallenge.
